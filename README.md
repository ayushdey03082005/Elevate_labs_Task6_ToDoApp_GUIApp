# 📝 TodoApp — Java Swing To-Do List

A simple desktop To-Do List application built with Java Swing. Add, view, and delete tasks through a clean GUI window.

---

## Features

- Add tasks via a text input field
- Delete selected tasks from the list
- Press **Enter** to quickly add a task
- Scrollable task list for longer to-do lists
- Input validation with friendly error dialogs

---

## Requirements

- Java Development Kit (JDK) 8 or higher
- No external libraries required — uses only the Java Standard Library (`javax.swing`, `java.awt`)

---

## Getting Started

### Compile

```bash
javac TodoApp.java
```

### Run

```bash
java TodoApp
```

---

## How to Use

| Action | How |
|---|---|
| Add a task | Type in the input field at the top and click **Add Task** or press **Enter** |
| Delete a task | Click a task in the list to select it, then click **Delete Task** |
